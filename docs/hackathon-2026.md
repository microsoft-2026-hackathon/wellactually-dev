# Microsoft Global Hackathon 2026 Guide

This document summarizes the event schedule, submission requirements, and
judging criteria that govern this project. The project targets both the judged
global Executive Challenge and Seoul Venue Local Judging.

## Event Structure

- Global Hackathon 2026 is a company-wide event run by The Garage.
- Official hacking takes place online and at venues worldwide. Team members may
  collaborate remotely from different locations.
- Global awards are judged at the Executive Challenge level.
- The Seoul Venue runs separate local judging. The supplied materials do not
  define Seoul judging as an official preliminary round for global judging, so
  the two paths must not be treated as dependent.

### Seoul Venue

| Date and time | Event |
| --- | --- |

| September 18, 2026, 09:00-12:00 | First-round review for all Seoul Venue projects, online and in person |

Because Seoul Venue judging occurs before the global video deadline, the MVP
and live demo must be ready before the first-round review on September 18.

## Global Submission Requirements

To be eligible for global Executive Challenge judging, the project must:

1. Include a Description on its Innovation Studio project page.
2. Select exactly one Executive Challenge.
3. Optionally select up to five Topic Challenges.
4. Upload a Project Video of no more than two minutes that explains or
   demonstrates the project and its value to the Primary Customer.
5. Submit the project by September 21, 2026, 11:59 PM Pacific Time.

A project that selects `Other` as its Executive Challenge is not eligible for
Executive Challenge judging. AI or machine learning may support initial sorting
and reviewer matching, but human judges select all winners.

## Global Judging Criteria

Evaluate every idea, MVP scope, user experience, document, and demo against all
five criteria.

| Criterion | Question for this project |
| --- | --- |
| Inspiration | Does it bring a fresh perspective, novelty, delight, or motivating energy? |
| Business Value | Is there a clear path to monetary or non-monetary value for Microsoft? |
| Customer Focus | Is the Primary Customer clear, and is this a compelling solution for them? |
| Feasibility | Is there a credible path to implementation and continued development? |
| Make Something | Has the team created something tangible that can be shown or demonstrated? |

## Seoul Venue Local Judging

The first round covers all Seoul Venue projects. Teams that advance are
notified individually before the second-round final. The supplied materials do
not define a local judging rubric, so do not assume it is identical to the
global rubric.

The confirmed local award paths are:

- Seoul Venue Local Award
- Korea Special Award (GitHub Copilot Agentic Coding)

A Seoul Venue Local Award winner may receive a `Korea 1st` tag on the Hackathon
site.

### Hack for Agentic Coding at the Seoul Venue

The Korea organizer guidance recommends the global `Hack for Agentic Coding`
Executive Challenge for projects focused on agentic software engineering. When
a project selects Seoul as its venue and joins this global Executive Challenge,
it is automatically enrolled in the corresponding Seoul challenge.

The Korea Special Award is separate from the global award. Its 2026 theme is
innovation in agentic coding experiences using GitHub Copilot. Suggested project
directions include:

- Multi-Harness Development: using multiple coding harnesses, such as Claude
  Code and Codex, within a GitHub Copilot-centered environment.
- Multi-Model Workflow: selecting and combining AI models based on the task.
- Multi-Runtime Development: moving development workflows between local and
  cloud runtimes.
- Next-Generation Agentic Engineering: improving engineering productivity with
  AI agents.
- Harness, Model, and Runtime orchestration beyond basic AI code generation.

These examples are inspiration, not confirmed judging criteria. The team has
chosen `Hack for Agentic Coding` as its target Executive Challenge. Evaluate the
eventual product idea against this challenge focus and all five global judging
criteria; building an unrelated product with an AI coding agent is not enough.

## Separate Reference Path: Agent Skills Challenge

`Hack Your Day Job with Agent Skills` is a separate non-judged Executive
Challenge for turning a day-job task into a reusable Agent Skill. It is not the
current target submission path and must not be treated as a product requirement.

If the team chooses this path separately, it must:

- Select that Executive Challenge on the project page and mark the project as
  writing code.
- Clearly describe the work task addressed by the skill.
- Upload the skill to the AI Skills Hub.
- Add the AI Skills Hub link to the Code Repository field in Innovation Studio.
- Not upload a Project Video or submit the project. The `Blocked from
  submitting` status can be ignored for this path.
- Add the Code Repository link by September 21, 2026, 11:59 PM Pacific Time.

## Policies and Operating Principles

- AI-assisted authoring is encouraged, and major tools used must be disclosed.
- Follow the Microsoft Standards of Business Conduct and the standard
  Hackathon IP policy.
- Apply Responsible AI and Secure Future Initiative (SFI) expectations to all
  project work.
- Do not include sensitive information, customer data, credentials, or
  internal-only material in demo data or the repository.
- External participants may be present, so explicitly review project visibility
  and data protection.

## Optional Support Resources

- Izzy supports idea discovery, customer and problem definition, team building,
  risk assessment, MVP and architecture design, development, demos, and
  submission review.
- The Korea GitHub Initiatives TF supports the progression from ideas to
  customer value and implementation through the HVE-CORE flow: `Design Thinking
  -> Research -> Engineering -> Scale`.
